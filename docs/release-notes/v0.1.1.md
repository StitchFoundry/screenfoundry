# ScreenFoundry 0.1.1

Free, open-source screen-printing prepress. This update is mostly the web app and the garment workflow.

## New
- **Start a print job from the garment**: pick the garment type, colour and print location (SC-12).
- **Web app**: smaller download with a progress bar and caching (#61), a favicon, page description and link previews (#68), and a staging switch for testing (`?services=staging`).
- **Report a Bug / Request a Feature** now open the StitchFoundry hub forms.

## Fixed
- An oversized source image is refused from its header instead of being loaded (#32).
- A flaky render test no longer fails on a placed document (#40).
- The web build's post-build steps run in one fixed order so they cannot overwrite each other (#82).

## Under the hood
- Customer-facing names and links now say StitchFoundry (organization move).
- Colour and tone-curve tests added; a clean-room check now runs in CI; dependency updates.

Early release: expect rough edges. Installers are signed for Windows and macOS when the release secrets are present.
